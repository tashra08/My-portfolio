Architecture & Design

Library Management System

This system was designed to model essential library operations through an evolutionary engineering approach, progressing through the following stages:

Phase 1: In-Memory CRUD Modeling

  • Constructed core domain models: Book, Member, and Transaction.
  • Implemented standard Create, Read, Update, and Delete logic with data structure collections.

Phase 2: Relational Schema & MySQL Storage

  • Designed normalized tables in MySQL with primary keys, foreign keys, and cascading constraints.
  • Enforced data integrity across book inventory counts and member checkout status.

Phase 3: Java Database Connectivity (JDBC)

  • Implemented the Data Access Object (DAO) pattern to separate business logic from SQL queries.
  • Handled connection pooling, PreparedStatement parameter binding to prevent SQL injection, and proper ResultSet resource cleanup.
